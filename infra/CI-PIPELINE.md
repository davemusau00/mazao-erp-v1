# CI/CD reference workflow
On every pull request: dependency lockfile verify, secret scanning, tsc/lint, unit, contracts, migration fresh and upgrade, API integration PostgreSQL, browser viewport and accessibility, offline replay tests, static analysis, image build. On main: produce SBOM/provenance, image digest and PWA hash manifest, staging deploy, smoke and restore check. Production requires signed approval and exact SHA; first roll API compatible with previous PWA, then atomic static symlink. Must block release when mandatory job red. Post-deploy verify endpoint/tenant isolation without creating paid demo orders. Document fallback to previous compatible binary, not blind down migrations.
